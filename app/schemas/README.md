# RILO Room schema

Room exports RILO's canonical initial schema as `io.github.peanutpersimmon.rilo.data.local.room.RidoDatabase/1.json`. The internal database class keeps its existing name; this JSON is RILO v1, not the former RIDO v1. No RIDO v1–v7 migration chain is supported. Future published schema changes require explicit migrations and tests.
